# MIDI 文件读取测试

`identity_four_notes.mid` 用于本地多声部身份诊断：4条、10秒、最大4同时音、MIDI60/64/67/72、力度80，四音同时起音，在4/6/8/10秒依次松开，记录CRC32 `6643E19E`。全部轨道/全部通道/移调0导入，先打开FPGA设置→more→FLASH INFO，再从手机主动播放。新诊断页标记为 `ID CHECK 01`；0～4秒正常显示 `SRC 000F RX 000F H 0000000F`。文件已通过App实际解析与逐条转换记录比对，实板结果仍待观察。完整步骤与判断表见[身份排查](../../docs/bluetooth_score/多声部身份排查.md)。

## 当前能力演示：小星星

`twinkle_capability_demo.mid` 是基于工程旋律重新编配的完整示范文件，适用于当前本地 **16自动声部开发版**。标准MIDI Format0、PPQN480、120 BPM，362条音符、82秒，音域MIDI48～83，最多16个同时音；转换后2896字节，CRC32 `911C00A0`。

| 时间 | 内容 | 最大同时音 |
| --- | --- | --- |
| 0～24秒 | 完整单旋律 | 1 |
| 24～26秒 | 休止，观察松音与效果尾音 | 0个按住音符 |
| 26～50秒 | 完整旋律加三音和弦 | 4 |
| 50～52秒 | 休止 | 0个按住音符 |
| 52～76秒 | 完整旋律、低音、和弦、高音铺底及分解和弦 | 8 |
| 76～78秒 | 休止 | 0个按住音符 |
| 78～82秒 | 两组16声部C大调结束和弦，含八度与同音加倍 | 16 |

手机App导入时选择**全部轨道、全部通道、移调0**，再应用筛选。预览应显示362条、82秒、最大同时16音、MIDI48～83。连接并验证FPGA后下载、主动播放；可在播放中测试暂停、继续和停止。如果使用曲库功能，可保存到选定槽位，再从FPGA的设置→more中选择、加载和播放。

文件采用5个MIDI通道区分旋律/伴奏的重叠音符，但当前FPGA统一使用所选音色，**并非分轨多音色**。不含踏板、弯音、音色切换或效果控制事件。先关闭效果听分段层次，再在FPGA切换现有效果器试听。休止处没有按住的谱音，释放包络和效果器尾音仍可能继续；82秒为最后Note Off，实际结束静音需实板观察。

已用App当前实际解析器逐条比对362条转换记录，验证各段1/4/8/16复音、休止、完整音域、无简化警告及模拟设备上传，共1462项检查通过。**未完成手机实传或FPGA试听**；该文件不能证明Flash、效果音质或硬件时序通过。旧单声部固件会因复音超限拒绝，应继续使用 `twinkle_single_voice.mid`。

生成：`python scripts/generate_bluetooth_examples.py --demo`。本次独立证据见 `reports/midi_capability_demo/generated.json` 与 `parser_validation.json`，不覆盖此前曲库联调报告。

`twinkle_single_voice.mid` 为完整单旋律《小星星》，由工程已有 `src/scores/twinkle.txt` 生成。

- 标准MIDI Format0，1条轨道，通道1，PPQN480，120 BPM。
- 42个音符，音域MIDI60～69，力度100，最大同时发声1音，无音符重叠。
- 最后一个音符结束时间23750ms；转换后336字节音符记录，CRC32为`7DE8EB5E`。
- 只有轨道名称、速度、音符起止和轨道结束事件，不含踏板、弯音或程序变更，不应触发简化演奏警告。

将文件传到手机，App选择“导入MIDI”，保留全部轨道、全部通道、移调0，点击“应用筛选与移调”。预览应显示42条音符、23.750秒、最大同时1音、MIDI60～69。连接模块并验证FPGA后，下载到琴再播放。

已通过App实际`MidiFile`解析、`Score`转换及当前1024条/单声部/MIDI48～83能力检查，逐条对照原曲一致；软件模拟上传分3个DATA包成功。日志与文件哈希见`reports/midi_twinkle`。尚未用手机导入或通过真实模块播放此文件。
