# 中英文切换和板载按键（2026-10-25）

本次基于 main 60c9deb，保留九级渲染＋一级连接器流水、无损动画压缩、矩阵双采样、现有音源和时序约束。蓝牙和超声波分支保持独立。

## 当前操作

- 默认英文；屏幕底部新增 120×44 的语言按钮 `[400,520)×[420,464)`，与所有原触摸控制不重叠。在英文界面显示“中文”，在中文界面显示“ENGLISH”，点击一次切换一次；按住／拖动不重复。
- 标题、音色、效果器、参数说明、状态和提示一起切换。音符 C4 等名称、PCM、Hz、数值和矩阵坐标保留通用记号；RESET 对应“恢复”。语言不改变音色、FX开关或参数、页面、主题、自动谱进度与持音。
- 英伦保留原英文花体、星图；中文使用毛笔风格。小猫配清雅中文；卡皮巴拉配可爱中文。彩蛋沿用英伦字体。三种中文字体均为真实字形的离线子集，保留各主题的配色、字号层级与标题抗锯齿；不是简单用方块或拉丁字母替代汉字。
- S0、S1、S2 完全停用，包括短按和长按，也不会抢占触摸命令。
- S3 只保留约 0.8 秒长按进入／退出隐藏彩蛋；持续按住只触发一次。短按及长按松开都不会开关效果器。退出恢复上次常规主题；屏幕主题按钮仍只循环三种常规主题。
- 页面用右上角“设置／返回”；主题用底部“主题 >”；FX开关在设置页触摸控制。矩阵菜单和演奏映射保留。USR依旧是整机复位：重播默认小星星并恢复英文／英伦等默认状态。

## 实现和资源边界

语言位由音频域 timbre_control 持有，复用原1112位原子显示快照的空位56。主题仍在55:54，音符、波形、触摸快照格式与GPIO不变。像素域仅在帧边界接收，不撕裂半帧语言。

字库保留原16384词英文数据逐字一致，增加89个汉字、三种字体和三张抗锯齿中文标题。单端口同步ROM扩至32768×16位（原16384×16），地址15位，中文正文16×16；沿用既有像素流水，不增加渲染延迟。不在硬件解码UTF-8、不加载完整中文字库。新增字形地址使用有界索引与分级字体基址，不在逐像素路径引入通用Unicode查找。

主题＋字库逻辑数据为2,217,512位（上一轮压缩后1,955,368位，加262,144位）；仍保留前一轮动画压缩。此值不是Gowin物理BSRAM占用或新STA结果。实际资源、布线耗时及全部时序须用户重新实现测量。

资源入口：assets/ui_language.json（文案）、assets/fonts/HighWaterChinese*.ttf（字体子集）、scripts/gen_ui_language.py（可重现生成）、src/config/ui_language.svh（字节编码词表）、src/rom/theme_font.hex（工程直接使用）。生成器只需已提交子集，无需联网／原视频。GPRJ已加入新头文件。

## 用户上板验证

下载完整main到新目录，重新打开keyboard_adsr.gprj再综合／布局布线；不要拼接旧HEX与新RTL。先检查全部时钟、I/O、复位路径的STA结果，本次未运行Gowin。

1. 英文默认、底部中文按钮在两页可点；切换后全屏中文、中文标题“高山流水”；按住不反复切换，ENGLISH可返回。
2. 三个常规主题及隐藏彩蛋的演奏／设置页均检查中文清晰、英文花体完整、背景与人物完整，没有方框／截字／乱码。
3. S0/S1/S2短按长按均无作用；S3短按无作用，长按一次进彩蛋、再长按返回，松手不改变FX。屏幕设置／主题／FX操作均可用。
4. 播放小星星、按住和松开单键／和弦时反复换语言、主题；曲谱不重启、音符不遗漏、松键正常衰减，FX关闭后切换类型仍关闭。
5. USR和断电重新下载后复测默认状态；将新综合资源、P&R耗时、STA报告发回。纯HDL与软件预览不等于实板验收。
