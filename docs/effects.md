# 效果器操作与实现

## 2026-10-22：三种效果（当前开发分支）

工作分支为feature/audio-effects，基于main的837748c；不合并、不改动codex/fpga-migration显示/触摸分支。屏幕可以保持拆下，矩阵键盘与杜邦线按现有位置保留。本版新增效果还没有实板试听，不能沿用旧回声的实板结论。偶发双键噪音仍为独立待处理项，本次不宣称修复。

| 选择编号 | 效果 | 实际声音处理 |
|---|---|---|
| 0 | 回声 | 150ms单次前馈延迟；稳态75%原声+25%延迟声 |
| 1 | 简易房间混响 | 四路不同长度的反馈梳状延迟，稳态75%原声+25%混响；形成短空间余韵 |
| 2 | 颤音（tremolo） | 约5Hz三角低频调制，音量在约50%到100%之间周期变化；不改变音高 |

三种效果一次选择一种，不是同时串联。房间模式只是四个并联反馈梳状滤波器，没有扩散全通、立体声空间建模或真实房间采样，不宣称专业混响音质。左右声道仍输出相同样本。

### 按钮操作

- S0/S1/S2仍直接选择正弦/笛管类/簧管类音色。
- S3轻按并松开：开启或旁路当前效果，动作发生在稳定松开时。
- S3按住约0.8秒：切换到下一种效果并自动开启，顺序回声→房间混响→颤音→回声。一直按住只切换一次；长按后松开不会再执行短按开关。
- 上电/USR复位：选择回声但默认关闭效果；自动《小星星》行为不变。演奏和自动曲谱期间都可选择效果。
- 两级同步、约10ms按下/松开消抖保留。矩阵键盘只演奏，不增加组合手势或菜单模式。按S3不会产生音符，也不会重触发已经按住的音。

无需屏幕的试听顺序：下载后先用S0、同一琴键比较轻按S3前后的短促回声；第一次长按S3松开后，用断续短音比较空间尾音；再次长按S3后持续按住一个琴键，听音量周期起伏；第三次长按返回回声。复位可以恢复已知初始选择。现在尚无屏幕/LED效果名称提示，长按次数从复位后的回声编号0开始计。

### 数值与平滑切换

新audio_effects模块位于voice_mixer和frame_buffer之间，保留原音符、波表、ADSR、分配器与功放策略。所有引擎按每个48kHz采样更新一次；没有新的音频时钟、浮点、CPU或显示依赖。

全局开关使用0..256的逐样本渐变，约5.33ms完成一次淡入/淡出。切换类型时先把旧效果淡出到原声，在权重为0时更换算法，再淡入；最大约10.7ms完成转换，不直接在非零效果间跳变。类型、权重及颤音相位在接收输入样本时原子锁存，处理中控制输入变化不改变正在处理的样本。旁路稳定后逐样本等于原混音结果；这里的渐变时间是设置转换时间，不是琴键输入响应延迟。

room的延迟长度为1499/1601/1867/2053采样点，约31.23/33.35/38.90/42.77ms。每路写回(input+old)/2，负数除2向零取整，避免-1量化残留永久循环；四路旧样本平均为混响湿声。该归一化反馈系数1/2稳定，各路及最终凸组合不增加输入峰值，末端另有16位饱和保护。

回声保留7200×16位环形历史，房间四路增加7020×16位，共227520位原始样本存储（约28.44kB十进制，未计BSRAM分块浪费、寄存器与DSP开销）。RAM分拍同步读取/写入，不整块复位；填充计数屏蔽未覆盖的旧内容。旁路时历史仍更新，重新开启可能包含此前实时演奏的尾音；这不是整段录音播放器。颤音32位相位每样本加447392，约5Hz；仅取三角相位计算增益。

audio_effects的ECHO_WET、ROOM_WET是0..256固定混合参数，默认64；TREMOLO_MIN默认128，LFO_STEP默认447392。它们目前是工程参数，不能在板上实时调节。当前运行时控制入口是enable与mode[1:0]；矩阵菜单、触摸调参和运行时强度入口留待下一阶段，不能把工程参数称作已经可用的UI调节。

### 接口与预算

- audio_effects：clk/rst、enable、mode[1:0]、in_valid/in_ready和有符号16位样本；out_valid周期必须被frame_buffer接收。合法类型0/1/2，3归一到回声。
- 接收输入后第3个后续时钟沿产生输出，下一拍可再接收；一个采样占用4个主时钟，不改变1280周期音频帧。
- synth_core尾部新增effect_mode输入；新顶层接timbre_control.effect_mode。旧仅音源TB不连接时按回声处理，生产顶层必须显式连接。
- 原audio_delay新增out_history，提供与其out_valid对齐的原始延迟样本；原直接回声接口、数学与两拍节奏保留，仅作为新引擎的历史存储使用。
- audio_reverb是独立四路反馈/平均引擎。总新增两个硬件模块，原GPRJ新增它们，源码仍在src；硬件约束、引脚、PLL和屏幕杜邦线均不变。
- 验证必须检查效果结果实际在32声部544周期预算内到达，而不能只引用原混音517周期。结果与限制见本次validation.json。

# 延迟效果器第一版

2026年10月19日新增可开关的单次回声，位于32声部混音之后、帧缓冲和PT8211串行输出之前。默认关闭，不增加硬件。当前是延迟效果，不是混响或合唱，也不是完整效果器组。

## 操作（2026-10-21独立按钮更新）

- 底板S3：回声开/关。稳定松开后再次按下才能再次切换，长按只切换一次。
- S0/S1/S2：分别直接选择正弦、笛管类、簧管类预设。
- 上电/复位默认回声关闭。S3在自动曲谱和手动键盘期间均可用，不产生演奏音符。
- 4×4矩阵键盘的两组对角组合不再控制音色或回声，完全用于演奏。
- 按钮编号、引脚和同步消抖详见[板载按钮](board_buttons.md)。下方日期条目保留历史行为，最新操作以本节为准。

试听时先关闭效果，用同一个键弹一段短促节奏，再打开效果重复。开启后应增加约150ms后的回声及松键尾音；原ADSR释放为200ms，最后声音最长可在松键后约350ms消失。持续长按纯音容易只听出音量/音色差异，短促节奏更容易比较回声。该效果不处理持续底噪。

## 算法与数值

采样率48kHz，延迟7200个采样点，即150ms。默认关闭时稳态逐样本完全等于原混音结果；开启时稳态为3/4原声＋1/4延迟声。开关使用64个采样点、约1.33ms的线性过渡，降低直接跳变。两种信号凸组合、32位有符号中间值和最终饱和保护，避免叠加后数值回绕。负数按算术右移向下取整。

单次前馈回声，没有反馈或无限尾音。延时线始终记录原混音，即使旁路时也更新；开启时可能听到之前150ms内弹奏内容。不是回放预录PCM，RAM只保存当前运行的实时合成样本。

src/audio_delay.sv用7200×16位环形存储，原始容量115200bit（约14.4KB，尚未计BSRAM分块开销）。RAM不逐项复位；复位清零指针/填充计数，未完整覆盖一圈前忽略旧数据，防止旧声音在重新启动后漏出。读取和写入安排在不同主时钟周期，不依赖同址读写模式。

## 接口与调度

- 新audio_delay：in_valid/in_ready接收一个16位有符号样本，下一拍产生out_valid/out_sample；每两拍可接收一次，不阻塞音频串行时钟。消费者必须在输出有效周期接收；本工程输出接原frame_buffer。
- synth_core新增effects_enable输入；独立输入适配器不变。
- 新增DELAY_SAMPLES参数默认7200，缩短参数只用于加速集成仿真，不改变生产默认值。
- 主工程增加audio_delay.sv，原PLL、CST/SDC、声部分配器、波表、ADSR、功放/静音策略保持。
- 原混音517周期交付仍适用；效果处理增加两拍左右的数据交付等待，仍须验证在544周期预算内。150ms是效果声与原声的间隔，原声不整体等待150ms，不能把它算作输入响应延迟。

## 仿真和验收范围

- tb_audio_delay对1、3、7200点延迟执行独立队列参考，覆盖脉冲位置/幅度、随机输入、正负满幅、旁路、开关渐变、脏RAM复位和处理中复位。
- tb_effects_integration对32声部混合音色、回声、串行输出逐帧核对独立数学模型，覆盖效果开关和复位。集成测试使用8点延迟加速，生产7200点由单元测试核实。
- tb_timbre_control检查两组控制手势彼此独立、保持不连跳及复位。
- 原RTL测试继续回归；证据在reports/effects/2026-10-19。当前环境没有官方PLL行为模型，本次不声称重跑vendor板级或物理引脚仿真。

用户需重新打开根目录keyboard_adsr.gprj，确认audio_delay.sv在列表，再自行综合/P&R。保留新资源、RAM推断及Setup/Hold报告，满足61.44MHz音频域要求后执行SRAM下载试听，不写Flash。HDL通过不代表硬件时序或音质通过。
