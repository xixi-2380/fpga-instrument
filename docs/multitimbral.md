# 多音色操作与验证

本次在同一主工程中增加三个合成预设：0正弦基准、1笛管风格、2簧管风格。后两者由少量谐波构造，不是原声采样，不宣称逼真还原真实乐器。默认上电为正弦。

## 操作

1. 松开所有键。
2. 同时按住左上角和右下角两个键约半秒，再完全松开。
3. 选择按正弦→笛管→簧管→正弦循环；保持不连跳，完全松开才允许下一次切换。
4. 用同一个普通键试听。组合键本身仍产生正常音符；松开后等约0.2秒尾音结束再比较。
5. 全部16个位置仍可演奏；正常演奏该精确双键和弦也会切换预设，这是当前控制手势的限制。换正式键盘后可改为独立控制键。
6. 持音和Release尾音沿用原音色，新起音使用当前预设；同音重触发使用新的预设。复位恢复正弦。

## 实现与限制

音符事件原子携带音色，回压期间保持稳定。分配器把音色与音符身份、频率一起记入各声部。原dds_sine保留32份相位，三个4096×16同步ROM同地址读取，延迟对齐后选择输出，保持原16周期时隙。这版使用三个ROM bank，不宣称只有一个物理ROM。

笛管相对谐波幅度为1、0.20、0.08；簧管第1/3/5/7谐波为1、0.60、0.30、0.15。各表独立归一化到16位峰值，相同峰值不代表相同主观响度。ADSR参数仍沿用原配置。

新增ROM约128Kbit（未计存储粒度），实际资源与时序需用户综合/P&R报告。单周期波形由scripts/gen_timbres.py离线生成，FPGA实时变调查表，不播放整段录音。谐波范围针对现有C4—D#5键域，未来扩展高音区须增加抗混叠措施。

GPIO、PLL、复位、输出格式和功放时序不变。未实现效果器或第二演奏维度，不把音色菜单自动计为第二维控制。底噪仍待定位。

## 验证

- tb_timbre_control：精确对角组合、保持不连跳、完全释放重新允许切换及复位。
- tb_timbres：3×4096采样点独立谐波数学对照，检查波形和ROM输出延迟。
- tb_multitimbral：32声部混合音色，与独立逐样本及串行输出数学参考比较，验证持音、释放、重用和重触发。
- tb_key_note_events：回压时音色和音符载荷稳定。
- 原RTL回归继续执行，结果见reports/multitimbral/summary.json。本环境无官方PLL行为模型，不声称重跑vendor板级仿真、物理引脚测试或Gowin实现。

Windows原仿真入口保持scripts/run_sim.py；可用--test tb_multitimbral或--test tb_timbres单测，须按tools/manifest.json准备Icarus。仿真通过不代表实板音质或时序通过。

## 2026-10-19：瞬间爆音与分配器时序修复

用户最新反馈为起音/切换瞬间爆音，普通双键也可稳定触发，并非只限左上＋右下控制组合。下载副本19:43:59的当前实现报告已读取：综合133秒、P&R等188秒，音频要求61.44 MHz，报告Fmax仅5.499 MHz，1762个Setup违例、0个Hold违例；最差路径在allocator，180级逻辑、181.520 ns，远超16.276 ns单拍预算。该副本src与修复前仓库仅CST不同；这些是修复前报告，不代表当前源码的新STA。

原voice_allocator不再在一拍内通过不断变化的候选索引比较32次年龄。现在逐拍读取一个上下文，下一拍只比较寄存后的元数据，选定声部及其rank再寄存后才令note_ready有效。未握手时不修改所有权；frame_ce或enabled撤销会取消并重查，外部valid/事件/音色必须保持到握手。32声部无打断搜索上限68个audio_clk周期，约1.107 µs；帧边界重试与渲染回压额外计入等待。各声部rank以常量索引并行更新，消除候选链与rank[target]组合反馈路径。

三种波表、32声部、原音色操作、ADSR、总增益、PLL、PA、4 mA对照约束和键盘分离保持。单音幅度、三种音色普通双键反复起音/独立松键、32混合音色和每个串行码均对照数学参考；不是通过静音、削减声部或降低时钟掩盖问题。搜索等待改变了部分事件被接收的帧，满幅测试改用每四帧起一声部的同相刺激；frame_ce只在主时钟边沿采样，不把组合CE的仿真delta瞬态当成新帧。

最终验证共21,228,787次检查通过：23项RTL、1项官方PLL板级（含三种音色物理双键）、2种引脚映射，以及1/4声部与32声部同相满幅变体。32声部仍517周期交付，首个非零串行码3.176972 ms；这些均为数字仿真结果。证据及初次测试刺激失败见[本次验证](../reports/multitimbral_fix/2026-10-19/validation.json)。
