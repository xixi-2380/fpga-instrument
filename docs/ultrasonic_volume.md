## 操作

进入原设置页，点击底部 **ULTRASONIC >**，进入独立子页。原音色、效果器、手动音量和 RESET 保留。

| 项目 | 默认值 | 操作 |
| --- | --- | --- |
| 超声波音量开关 | OFF | 开启后接管总音量，关闭后手动接管 |
| 灵敏度 | 1 / 5 | 1～5 档，每次一档 |
| MIN VOLUME | 0% | 每次 5%，不能超过 MAX |
| MAX VOLUME | 100% | 每次 5%，不能低于 MIN |
| 距离 | --.- CM | 有效跟踪时显示一位小数 |
| 当前音量 | 原手动值 | 显示送给主音量模块的实时百分比 |

开启时，原设置页的手动音量加减按钮置灰，触摸和板载 S1/S2 的音量加减均不覆盖自动控制。关闭时保持当时音量，后续手动每次加减 5%，范围仍为 0～100%，不受自动控制上下限约束。自动控制后可能留下任意整数百分比，例如 43%；关闭后按减得到 38%，所有 0～100% 值均支持。

上下限允许相等，此时自动音量固定在该值。修改上下限立即约束目标，实际音量平滑趋近，不产生突然跳变。开关、参数均为本次上电的设置，USR/上电或主设置页 RESET 恢复默认值；没有加入非易失存储。RESET 是明确恢复默认，音量恢复 100%。普通 OFF 切换保留当时音量。

矩阵键盘可在触摸不可用时操作；菜单期间仍不触发音符：

| 页面 | 键位 | 动作 |
| --- | --- | --- |
| 原设置页 | R1C4 | 进入超声波子页 |
| 原设置页 | R4C1 / R4C4 | RESET / 进入more曲库 |
| 超声波子页 | R1C1 | 开关自动控制 |
| 超声波子页 | R2C1 / R2C2 | 灵敏度减 / 加 |
| 超声波子页 | R3C1 / R3C2 | 最低音量减 / 加 |
| 超声波子页 | R4C1 / R4C2 | 最高音量减 / 加 |
| 超声波子页 | R1C4 / R4C4 | 返回原设置页 |

子页右上角 BACK 返回原设置页；长按 S0 返回演奏页，自动控制可继续运行。合并后原设置页R1C4进入超声波，R4C4进入more曲库。矩阵演奏键位、单键识别、释放后重装和鬼键保护保持。

## 距离映射与异常行为

| 灵敏度 | 覆盖上下限的手势范围 |
| --- | --- |
| 1 | 5～40cm |
| 2 | 5～35cm |
| 3 | 5～30cm |
| 4 | 5～25cm |
| 5 | 5～20cm |

距离越近，音量越大。有效范围内按毫米作线性映射并四舍五入到 1%；距离到近端时目标为 MAX，到该档远端及以外时为 MIN。2～5cm 的有效近距读数夹到 MAX；小于 2cm、超过 40cm、无回波及高电平超时均不进入滤波与音量更新。

有效读数经过三点中值滤波；第一次有效测距直接建立历史，随后过滤单个突变读数。短暂异常保持最近目标，约 1 秒没有有效读数则目标回落到 MIN（1ms 时间基准量化）。目标变化后每 2ms 移动 1%：跨越全范围约 200ms，继续通过原主音量模块的逐采样增益渐变，避免切换爆音。首次开启也从当前音量平滑接管；配置版本号随开关和参数更新，过期目标不会跨越配置更新覆盖当前值。

状态：OFF（关闭）、WAITING（等待首个有效回波）、TRACKING（有效跟踪）、HOLDING（短暂异常、保持）、NO ECHO（持续异常、回落下限）。只有 TRACKING 显示当前有效距离，其余显示 `--.-`，不把旧距离作为当前读数。音量上下限约束目标；平滑接管期间实际音量可能尚未进入新范围。

## RTL 和时序

- `ultrasonic_range.sv`：50MHz 参考域，1µs CE，12µs Trig，触发间隔至少 60ms，无回波/高电平超时各 30ms。上电默认不触发。以回波宽度计算毫米：`round(us*5/29)`，由有界逐拍减法实现；没有组合除法器或新增时钟。
- `ultrasonic_volume.sv`：同参考域作中值、1ms 新鲜度判断和映射。乘法结果先寄存，比例计算最多 100 次窄位宽减法；BCD 距离分九拍生成，不向像素域增加距离换算。
- 音频域 `timbre_control` 维护开关、参数、版本及音量所有权，自动模式每 2ms 最多改变 1%。33 位配置、30 位结果分别用现有四相握手快照跨域。
- `master_volume.sv` 精确支持所有 101 个整数百分比，沿用原两级 PCM 流水及逐采样渐变。音量仍位于效果器和限幅之后，0% 不释放声部；不改变 24 倍补偿、限幅窗口、I²S 或 LAT 计时定义。
- 显示原 1133 位字段位置保留，最高处追加 34 位子页、开关、灵敏度、上下限、回波状态和 BCD 距离，总快照 1167 位。保留三拍渲染加统一管脚输出寄存器。
- 仅为 Trig 增加 100ns 输出布线预算；未降低内部频率或添加整组异步时钟例外。新 UI 与模块仍需要新的 Gowin 报告确认资源、时序和实际布线耗时。
