# 七种实时合成音色

本轮在feature/instrument-ui保留旧三音色，新增大提琴、钢琴、木吉他、颤音琴。都是谐波波表与独立包络的合成近似，不使用整段PCM/录音，不宣称采样级仿真或真实弓弦物理建模。实际音色辨识、音量平衡和听感待用户试听。

| ID | 名称 | 实现与包络 |
|---|---|---|
| 0 | SINE 正弦 | 原ROM、原ADSR |
| 1 | FLUTE 笛管类 | 原ROM、原ADSR |
| 2 | REED 簧管类 | 原ROM、原ADSR |
| 3 | CELLO 大提琴 | 1～8次谐波、约42.7ms起音；向75%幅度收敛并持续；松键≤42.7ms |
| 4 | PIANO 钢琴 | 基频与递减泛音、约1.33ms起音，按住也会指数式衰减；松键≤21.3ms |
| 5 | GUITAR 木吉他 | 拨弦式谐波比例、约0.67ms起音，较快衰减；松键≤10.7ms |
| 6 | VIBRAPHONE 颤音琴 | 基频加4、10次泛音、约2.67ms起音、较长衰减；松键≤42.7ms |

以上按48kHz和独立新包络计算；颤音琴为击奏金属音色近似，没有强制自带颤动，需要时可选已有TREMOLO效果。现物理键盘音高仍C4～D#5，大提琴在这一音区演奏，不自动移调或扩大键数。

新四表各4096×16，共262144bit逻辑初始化数据，加旧三表共7表；实际硬件映射须用户新综合确认。所有波表峰值归一到±32767且均值为零，现有1/32声部增益和16位最终饱和保持。`scripts/gen_timbres.py`可重建，旧三ROM字节不改。最高10次谐波在当前键盘音区低于Nyquist；未增加多频带抗混叠表，扩展至很高MIDI音区时须另做频谱检查。

音色编号全链路由2位扩至3位，覆盖key_note_events、keyboard_core、timbre_control、voice_allocator、dds_sine、synth_core、score_player、顶层与显示。ID7/仿真未知输入降为正弦。选择预设不改已发声声部；下一次Note On原子携带新ID。32声部各保留相位、音色和包络，共享同步波表读出，未改变16时钟槽和原517/544周期渲染预算。

新增instrument_envelope封装旧ADSR与新四类常量移位包络。旧三类的参数/输出行为保持；同ID重触发在原相位与当前幅度继续，新声部重新起音。新旧包络之间通过ADSR的可选seed_valid/seed_level衔接，避免切换时直接丢失当前幅度。新声部/复位仍清零；新包络仅按sample_ce更新，不新增内部派生时钟。新版ADSR位置参数调用须补齐末尾两个seed端口，命名调用可省略；只有seed_valid明确为1才使用seed_level。

曲谱ROM仍64位、ID位40:34不变，音色低2位仍33:32，高位使用原保留bit41。新编译器支持cello/piano/guitar/vibraphone和0..6；原twinkle.txt编译结果与原hex逐字节一致，默认小星星不改编。新格式只在本分支可用，旧分支不能读取高位音色。新音色的自定义曲谱，END后的TAIL_FRAMES须覆盖实际释放（至少2048帧）；生产默认9604帧满足，不能套用缩短为数帧的测试参数做实板曲终验收。

后续与周同学MAX98357A/触摸合并时，保留本轮三位音色与效果器前后关系，再替换最终串行器/引脚；不直接以旧synth_core覆盖本版。与杨同学蓝牙对接时，保持valid/ready下note_on、7位note_id、32位note_fcw、3位note_timbre稳定，明确事件源仲裁和音符ID映射；本轮未实施蓝牙或多来源并发。
