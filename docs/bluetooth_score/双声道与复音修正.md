# 两块 MAX98357A 双声道与蓝牙复音修正

> 本文记录8f10059上游方案。当前已合入fpga-instrument-integrated，保留超声波、前瞻限幅、LAT及本地时序修正；当前状态与验证以[合并说明](../stereo_integration_2026-10-27.md)为准。下方“不合超声波”、旧时序数值与reports/stereo_polyphony仅属于来源提交。

本轮严格基于 `codex/bluetooth-score-integration` 的 `2d86834782dcdd82b6ab2c5c81940da5506340ec`，不合入 main、超声波或触摸指引分支。保持当前单英伦界面、蓝牙协议、App/曲库、U7区域与写入限制、七音色、32物理声部/16自动声部、触摸、屏幕音量、全部球位和时钟目标。上电/USR仍静音待机，不恢复小星星自动播放。

## 1. 改动与复现

旧调度器最多16个自动身份，某个音符结束后立即允许身份复用。旧音源按身份匹配仍在释放的声部，且按该身份读取力度：例如身份0的C4尚有尾音，新G4也分到身份0，旧尾音会被改为G4频率和新力度，并从原包络电平重触发。这是可在纯RTL复现的音高/音量突变，不只是主观听感。

`tb_bt_tail_reuse` 在原 `2d86834` 上复现断言失败：`reused scheduler identity must not retune the old release tail`。修正后，自动事件只匹配仍按住/待起音的所有者，已释放声部保留原频率/相位/包络/力度/音高；复用的身份为新音分配空闲物理声部。音符Off只释放当前按住的对应自动身份。力度和显示音高移到每个物理声部保存，不能再从可被复用的16项来源表读取。旧16项表仅留为仿真诊断，不参与发声。

物理容量仍为32；满额时仍按原规则替换最旧已释放声部，再考虑按住声部。不能承诺无限叠加尾音；已有32声部上限不变。手动/旧调用者未启用自动身份语义时，保持原同音重触发行为。

这修正了明确复现的逻辑缺陷，但不能把所有实物电音都归因于它。该分支原用户11:27报告ref/audio/pixel Fmax为43.703/40.291/25.897MHz，低于50/61.44/35MHz；本轮没有运行Gowin，不能宣称时序已修复或上板电音已完全消失。峰值包络比较显式改为平衡树，其他域的现有时序问题仍须按新报告处理。

## 2. 双声道音频

生产 `keyboard_top.STEREO_ENABLE=1`，不增加GPIO。每个声部按起音时的音高固定声像，释放期间不改变；采用可精确复现的移位权重，没有动态除法或实时浮点。

| MIDI音区 | 左侧幅度 | 右侧幅度 |
|---|---:|---:|
| <60 | 3/4 | 1/4 |
| 60～65 | 1 | 1/2 |
| 66～71 | 1/2 | 1 |
| ≥72 | 1/4 | 3/4 |

这是合成器自动音区声像，不是MIDI文件中原轨道的左右PAN复现。现有8字节曲谱记录不携带声像或分轨音色，本轮不更改协议/App。单个音也可能在两侧均有声音；音区不同，左右权重不同。低/中/高音和弦可以明显区分两侧内容。

左右分别使用独立40位混音、效果器历史、音量流水，最终由原 `frame_buffer` 成对缓存，原I²S串行器输出真正不同的左右16位样本。屏幕音量同时调节两侧，效果类型、参数、旁路同步，但历史不混合；波形/电平观察左右最终PCM的有符号平均值。默认采样率48kHz、BCLK1.536MHz、audio_clk61.44MHz、每帧1280拍保持。

独立 `synth_core.STEREO_ENABLE` 默认0保留旧数学参考/调用接口，板级默认明确传1。若暂时只有一块功放，仍可试听它选中的声道；这不等于两路硬件验收。把顶层参数设0可以生成原单声道复制到左右的对照版本，自动尾音修正仍然有效。

独立左右效果会增加RAM/DSP/逻辑用量；不声称资源数或布线时间已经测得。没有改约束、降频或屏蔽业务时序路径。

## 3. 两块功放接线

两块模块均应为 **MAX98357A**，每块驱动一个独立扬声器。功放供电、阻抗和板上默认电阻按实物确认。

| FPGA现有信号 | 球位 | 左模块 | 右模块 |
|---|---|---|---|
| MAX_BCLK | V22 | BCLK | BCLK |
| MAX_LRCLK | W19 | LRC/LRCLK | LRC/LRCLK |
| MAX_DIN | Y20 | DIN | DIN |
| MAX_SD_MODE | V26 | 左声道选择/关断电路输入 | 右声道选择/关断电路输入 |
| 真实GND | 原GND | GND | GND |

**不能把两块SD都直接接到V26高电平后就认为得到左右声道。** MAX98357A通过SD/MODE模拟电压选择左、右或左右平均。官方芯片典型范围：低于0.16V关断；0.16～0.77V左右平均；0.77～1.4V右；高于1.4V左。实际保证阈值、电阻误差和板上外围须以数据手册与实物为准。

参考原厂 [MAX98357A/MAX98357B 数据手册](https://www.analog.com/media/en/technical-documentation/data-sheets/max98357a-max98357b.pdf) 的Table 5/6及SD_MODE说明。对于**无额外板载偏置**、内部典型100k下拉、3.3V控制源，原厂右声道上拉示例约210.2kΩ；这不是适用于所有淘宝模块的直接接线处方。有板载5V上拉或焊桥时，必须先核对电路，否则声道选择和关断都可能不正确。不得把SD同时直连电源与FPGA输出。

建议先确认两块板的SD/声道焊桥资料或清晰正反面照片，再确定右侧电阻连接。正常工作时测得左SD处于左区间、右SD处于右区间；复位/失锁时两块都应进入关断区间。两块VIN接合适外部电源并共地，不从GPIO供电；每个扬声器只接自己功放的OUT+/OUT-，两块功放的功率输出不并联，OUT-不接地。

## 4. 上板验证顺序

1. 下载本分支完整新包，在新目录打开 `keyboard_adsr.gprj`，从综合重新开始，由用户运行P&R和STA。不要使用旧`.fs`或本分支dist中2026-10-25的历史编译产物。
2. 核对资源、50/61.44/35MHz目标、Setup/Hold/Recovery/Removal及无新增欠载；现有时序未达标不能作为稳定验收。
3. 先在低音量确认左右模块声道选择，用低/高音对照左右权重；若两侧始终完全一样，先查SD模式与接线。
4. 手动单音、和弦、七音色与松键，屏幕0/50/100%音量；确认两侧均静音/恢复且不重触发。
5. 蓝牙1→4→8→16音及快速换和弦，重点听相邻和弦间的尾音，不应出现旧尾音突然变成新音；测试重复同音、不同力度、暂停/继续/停止、自然结束和USR重启。
6. Echo/Room/Tremolo及FX OFF逐一回归，再测试手机断开后本地曲库操作。新源码不意味着最新Flash/App功能已实板验收。
7. 若仍有电音，保留当前位流、完整STA、问题MIDI和具体时间点，区分逻辑/时序/电源与功放因素继续排查。

纯HDL证据位于 `reports/stereo_polyphony/2026-10-27`。新数值测试覆盖32个物理声部、七音色、变力度、尾音重叠、左右独立效果、0%音量、逐字I²S、清空与复位；短效果延迟用于高效覆盖，不能当真实150ms效果听感。现有生产时钟播放器/三种效果联合测试另行覆盖。所有PLL替代均为明确仿真模型，不是vendor或STA验证。
