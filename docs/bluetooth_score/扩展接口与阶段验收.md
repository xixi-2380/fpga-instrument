# 八阶段扩展：接口与验收记录

开发起点为蓝牙分支 `8081710`，基准仍为 `bf5df5792f654ee9c29a30983cdbe83a0061669e`。本次工作只在原蓝牙工作树内推进，不改 main，不运行 Gowin 或烧录。用户已授权第二颗 U7 Flash 全部用于曲库；仍需实板读回 JEDEC ID 核对型号和核心板版本。

## A：冻结的边界

- 自动事件保留 23 位 `{kind[1:0],id[6:0],pitch[6:0],velocity[6:0]}` 原子握手。kind 为 Off=0、On=1、Silence=2；自动身份 0..15，手动 MIDI 身份60..75。Off按身份，不按音高。同音重叠独立；已释放身份复用沿用原分配器同身份重触发语义，不无限保留旧尾音。
- 活动RAM容量4096×64，下载与Flash载入共用。8字节记录格式与v1 HELLO 20字节保持；HELLO声明4096条/16声部/功能位0与2，功能位1仍为0。旧App的RAM下载不自动写Flash。
- 控制、存储、目录在50MHz域；音频61.44MHz，像素35MHz。普通On/Off不flush；上传接管、播放重启、暂停和停止通过Silence等待实际双声道零值确认。恢复重新起音，不宣称相位续播。
- 共享RAM外部服务锁仅在停止、无上传/播放器事务时取得；锁内拒绝手机上传/播放和本地冲突操作。状态读取可继续。Flash加载完成仍须通过相同CRC/格式/复音校验后才可播放。
- Flash驱动采用参考时钟CE推进SPI模式0；不生成内部SPI时钟域。底层请求有界，页编程不跨256字节、擦除4KiB，不提供整片擦除。实际识别、允许地址、WEL和保护位均须满足才写入。
- 曲库固定32目录项、至少1备用槽；双目录+CRC+代数+最终提交标记。先写数据并核验，再提交新目录。UI只收定长状态/当前条目，不搬运整目录。
- 存储任务为异步：启动返回任务ID，状态含忙/完成/失败和错误；持久成功只能在读回与目录提交后报告。协议扩展与v1上传分开，防止改变COMMIT含义。
- more采用独立动作编号，原UI_MORE=效果加量保持。more只做按钮/触摸适配与字符显示，不实现Flash业务。

## 周期和资源预算

生产音频每帧1280拍，32物理声部顺序渲染预算544拍；自动16声部不复制音源/效果RAM。分配器每事件最多约68拍搜索，加帧等待与CDC，应在1ms内处理16 Off+16 On；以真实50/61.44MHz联合测试验证，不将加速单声部测试当生产证据。自动力度/音高仅16上下文，避免128条通用大MUX。

最新用户11:27构建报告参考43.703/目标50、音频40.291/目标61.44、像素25.897/目标35MHz，三域未闭合；报告归档见[发布记录](发布记录_2026-10-25.md)。音符高亮读取已分级，后续仍需按实际关键路径处理。任何结构改进都不是STA通过结论；重新运行STA仍由用户执行。

音频时序结构已将frame_ce边界预测为寄存器输出，削减计数器解码直达ADSR的控制路径；1/2/20拍半周期边界等价测试通过。音符高亮按元数据/音高/位图分级，力度计算多两拍流水；32声部交付519拍，仍在544拍预算内。没有新增内部派生时钟、宽泛false path或放松原音频/像素要求；实际Fmax必须由新报告判断。

Flash几何与任务格式已写入独立[扩展协议](曲库扩展协议.md)。用户已授权U7全部用于曲库，软件仍仅使用所需2.125MiB区域。当前芯片白名单只覆盖已实现配置，不能用仿真ID冒充实物识别。
