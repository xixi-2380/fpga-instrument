# GM 鼓键与锣声近似

本版 App 可以读取第 10 通道的 GM1 打击乐键 35～81，并转换成琴端已有的 10 种鼓音。**这是 47 种标准键的兼容近似，不是 47 种独立采样或完整 GM1 音源。** 原先可达的 22 个鼓键和音色 ID 16～25 保持不变，旧 8 字节协议也保持原样；鼓曲使用现有 12 字节多音色协议。FPGA 无需为此增加 ROM、振荡器、乘法器或声部。

GM1 第 10 通道是按键号选择打击乐，52 的标准名称是 Chinese Cymbal（中国镲）；表中没有专用 Gong（锣）键。来源为 [MIDI Association GM1 规范入口](https://midi.org/general-midi-level-1)，其官方链接的 [GM1 PDF](https://drive.google.com/file/d/1TTM2HI2JAp_XiTJYEJ8gPNvuJpIjJiTP/view) Table 3。锣声近似是本工程的可选编配处理，不更改 GM 标准含义。

## 使用方法

1. App 选择“按原谱音色”或“统一旋律”，保留第 10 通道。默认不勾选“排除第10通道鼓轨”。
2. 导入 MIDI 后应用筛选与移调。旋律可移调，鼓键不随旋律移调；GM1 范围外的鼓起音会明确报错。
3. 如需锣声近似，勾选“52中国镲叠加低鼓，模拟锣声”。默认关闭；开启后，每个原始 52 起音保留原中国镲，再加同拍、半力度的 41 低鼓。短 Note Off 或缺少 Note Off 都不会截断琴端固定的一次性鼓音；旋律的起止配对检查仍严格保留。
4. 查看转换预览和近似警告，再上传。每个叠加起音占两个自动声部；8 个同时叠加恰好用满 16 个自动声部，9 个会被拒绝，不能通过降低统计来绕过限制。音符总量也按实际展开后的记录检查。

无需准备 MIDI 也可点击“鼓镲／锣声近似示例”：不勾选时为底鼓、小鼓、闭镲、Crash、中国镲；勾选时只在最后中国镲加入低鼓。它与示例 MIDI 经实际解析器转换的记录已逐字节比对。

## 对应表

原 22 个键为 35～53、55、57、59，均原样发送。其余 25 个标准键在手机端改为下表已有代表键，琴端继续看到旧协议支持的键和 ID；每种近似均复用已有音色的固定包络时长。

| 输入键 | 发送键 / 琴端 ID | 采用的已有声音 |
|---|---|---|
| 54、69、70、73 | 42 / 19 | 短噪声闭镲，近似摇奏/摩擦类 |
| 56、67、71、80 | 53 / 25 | 短铃/金属打击近似 |
| 58 | 39 / 18 | 拍手式噪声近似 |
| 60、65、75、76 | 50 / 23 | 高频鼓击，近似短小鼓/木击 |
| 61、66、77 | 45 / 22 | 中频鼓击近似 |
| 62、78 | 48 / 23 | 高频鼓击近似 |
| 63 | 47 / 22 | 中频鼓击近似 |
| 64 | 41 / 21 | 低频鼓击近似 |
| 68、72 | 51 / 25 | 较长铃/金属打击近似 |
| 74 | 46 / 20 | 开镲式噪声近似 |
| 79 | 43 / 21 | 低频鼓击近似 |
| 81 | 59 / 25 | 铃/金属打击近似 |
| 52，选中锣声近似时 | 52 / 24，加 41 / 21 | 原中国镲加半力度低鼓，两条记录 |

例如原始牛铃、哨音或木块键可随曲目保留节奏，但不会变成独立的真实牛铃、哨音或木块采样。若这些音色的逼真度是关键，应使用专用音源；本方案优先兼容现有实板与有限资源。

## 文件与 APK

- `android/examples/gm1_drums_china52.mid`：标准 Format 0、PPQN480、120 BPM，5 个 GM 鼓起音，不包含自定义锣号；未开叠加时 5 条、5 秒、最大 1 音，开叠加后 6 条、5 秒、最大 2 音，数据 CRC32 `488E9EB5`。
- `android/examples/gm1_percussion_47.mid`：35～81 逐键演示，每击相隔 2 秒。App 转换后 47 条、93 秒、最大 1 音；部分键有近似警告。用于检查键映射，不代表 47 种不同音色。
- 新 APK 为 `android/dist/GaoshanScore-0.5-percussion-20261102.apk`，包名 `cn.whu.gaoshan`，versionCode 8，Android 8.0/API26 起。已通过编译、D8、打包和 v2/v3 签名校验，没有在手机安装或通过蓝牙实传试听。

本机没有找到旧开发私钥，因此本版使用新的本地开发签名；签名证书与旧 0.4 不同，Android 无法直接覆盖安装旧版。保留旧 App 与其本地信息，先不要把安装失败当作连接或 FPGA 故障；若找回旧私钥，可用构建脚本 `--keystore` 重新签成兼容升级包。这里没有执行卸载、安装或清理用户数据。

验证证据在 `reports/adjustments_20261101/percussion/validation.json`：Java 核心、47 键/叠加/兼容测试，以及同一 6 条 Java 导出记录通过未改的生产 FPGA 验证器与播放器；10 个原鼓包络均在规定帧数结束且有非零波形。行为仿真不替代实板音质或蓝牙无线验收。
