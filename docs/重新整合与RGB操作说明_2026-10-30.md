## 接线与灯序

- 21颗WS2812的第一颗DIN接P25，开发板与灯带GND共地；灯带按额定电压供电。P25是3.3V信号，DIN所需电平按实际灯带确认。
- 原73个信号引脚保持不变，只增加P25。颤音旋钮A/B/SW仍为T23/R25/W23。
- LED0～6对应C4、D4、E4、F4、G4、A4、B4；LED7～13对应C5～B5；LED14～20对应C6～B6。反接灯序时在页面选择REVERSE。
- `src/ws2812_driver.v` 与用户提供的 `E:/gowin/rgb led/ws2812_driver.v` 一致，使用50MHz时钟，发送GRB数据。

## RGB页面

按原方式进入设置，点击底栏RGB。开关和参数通过触摸立即生效，不占用板载按钮或旋钮。

| 控件 | 作用 |
| --- | --- |
| TURN ON / TURN OFF | 整条开关；关闭发送黑帧 |
| SOLID | 常亮所选颜色 |
| BREATH | 所选颜色以2秒周期呼吸 |
| RAINBOW | 彩虹流动 |
| KEY LINK | 按键联动 |
| 八色块 | 红、橙、黄、绿、青、蓝、紫、白 |
| BRIGHT − / + | 每次5%，范围0～100% |
| DIRECTION | 切换NORMAL/REVERSE灯序 |
| BACK | 返回原设置页 |

默认关闭、蓝色、10%亮度、NORMAL。参数仅运行期间保存，复位或恢复默认时回到默认值，不写Flash。

KEY LINK显示21个物理白键。蓝牙只显示合成器接受并仍按住的C4～B6白键，黑键、鼓音及范围外音符不点灯。同音重叠直到最后一个身份松开才灭；STOP清灯。松键后灯灭，不跟随延音和混响尾音。
