# 实时频谱与李萨如／延迟XY（2026-10-26）

基于main7e0aaec，纯FPGA实现，保留四主题、中英文、七音色／32声部、三效果器、小星星及触摸。无需新增硬件或改接线；蓝牙、超声波分支未合并。

## 操作

屏幕底部新增 **VIEW >／视图 >**，按 **波形→实时频谱→李萨如→波形** 循环，按住不重复。按钮范围[264,384)×[420,464)，120×44，两页均可操作；设置页切换后返回演奏页查看。换视图不改音色、效果、参数、语言、主题或曲谱。S0/S1/S2继续停用，S3仅长按彩蛋；USR复位重播小星星并恢复默认英文、英伦和波形视图。

频谱：显示真实post-FX音频的64个频带。横轴0至接近24kHz，低频细分、高频合并；纵向为相对对数幅度，非校准dBFS。FFT WAIT／频谱准备表示第一窗口未完成。改变音高、音色、和弦或效果器会改变谱形；松键后的ADSR、效果尾音和旧窗口短暂保留均正常。

李萨如：目前音源单声道，左右输出相同，不能假称独立立体声图。采用真实 `X[n]` 和 `Y[n]=X[n-16]`，标注MONO DELAY XY／单声道延迟XY、16 SAMPLE DELAY／延迟16采样。48kHz下延迟约0.333ms；单正弦随频率呈线、椭圆或圆，750Hz对应约90°相位差；复杂音色和和弦产生复杂轨迹。它是单声道延迟相图，不是独立声道相关度或两个独立通道的频率比测量。

XY沿用原波形X8显示幅度及4:1抽取；取点4..127和对应前4点，避免首尾跨窗口拼接。图形有显示量化／裁剪／抽取混叠限制，不能代替仪器。显示增益只影响画面。主界面128×128、彩蛋64×64，人物和脚仍在左侧完整展示。

## 实现

- audio_spectrum.sv旁路接收visual_sample_valid/sample，不向音源回传ready、暂停或数据。窗口2048个连续采样，Hann Q0.15、2048点基2DIT FFT、旋转系数Q2.14，每级缩放1/2。频点间隔23.4375Hz；窗函数会拓宽峰，不能承诺任意相隔23Hz两音均可分辨。
- 实／虚部各2048×16同步双口RAM，输入反序、顺序蝶形。窗函数单独乘法，旋转四次乘法复用一处表达式。组峰值、最高有效位、归一化移位及打包分拍，不把编码／移位／加法串在同一长路径。不使用CPU、MCU、实时浮点或派生内部时钟。
- 分析FFT频点0..1023，每带取abs(real)+abs(imag)近似幅度的最大值，经相对对数转换为0..127。分组边界见assets/spectrum_config.json：前32带单频点，其后逐渐变宽。高频多个峰可能合并为一柱，不能凭64柱直接统计任何组合下的32声部。
- 每帧采集约42.67ms，目标61.44MHz下计算约1.52ms，理论约22次/秒。计算期间不采入下一分析窗口，声音仍接收全部样本；这是可视化采样间隙，不是音频丢样。定点量化可形成低幅度分析底部，不能直接据小柱判定模拟底噪。数字零窗口谱柱严格为零。
- 原1112位原子快照保持宽度：58:57视图，56语言，55:54主题，63:59保留。新增独立513位原子CDC传送ready+512位谱柱；像素域只在帧边界冻结它。原71位触摸桥不变。
- lissajous_plot.sv完全在pixel_clk域运行，Bresenham线段写入不显示的64×64位图，后台清除和绘制，帧边界交换双缓冲银行。同步读一拍与原背景ROM对齐，原九级renderer＋一级连接器保持；XY比当前音符／电平约晚一个显示帧。

## 资源与整合边界

新增FFT工作数组、窗／旋转ROM、两个4096位XY位图和513位状态桥；三套字体扩充至实际105汉字，仍使用原32768×16字库容量。动画／人物HEX和无损压缩、GPIO/CST、PLL参数、50/61.44/35MHz目标、音源／ADSR／效果器不变。

实际BRAM／DSP推断、P&R耗时和STA必须由用户重新运行Gowin。检查FFT数组和XY位图是否推断为合适RAM，避免大规模LUT存储。SDC仅补充analysis_bridge两个真实异步复位同步器PRESET入口的精确名称，需从新网表核对匹配；普通数据、下游复位、I/O和原时钟目标仍检查，未加数据false_path、多周期或降频。

未来合并超声波主音量时要统一可视化抽头在主音量前还是后；当前沿用post-FX抽头，不暗中合入master gain。蓝牙动作码与状态位另有冲突，正式整合时处理。
