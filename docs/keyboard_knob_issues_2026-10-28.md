# 键盘与旋钮问题追踪

本次实际测试来源为integrated，新副本为pcb-flash-debug。此前针对timing-audio-fix的结论只作为来源审查，不等同于用户当时所烧录版本。

| 问题 | 软件处理 | 实板状态 |
|---|---|---|
| PCB1无声 | 增加初始化/回读/在线/数据有效/路由资格/音符链路诊断 | 尚未重新测试 |
| PCB2背面轻托触发、三板灵敏度不同 | 独立GSR与16路KOR、两次确认、运行时回读与标定页面 | 物理阈值与供电环境待标定 |
| PCB2/3漏键、误触 | 分离合法读值变化与通信掉线；50ms数据过期止音与恢复重武装 | 待实板对照 |
| 旋钮1每格切PCB1 ON/OFF | 实际源码与旧网表未见字段/球位重叠；新增旋钮与PCB故障关联历史，修复未收敛时序 | 根因尚不能凭仿真认定 |
| AUX误触修改设置 | 生产默认关闭12个AUX控制，保留原始采集 | 需新位流生效 |
| Flash保存失败 | 整条移植交接修复，补probe_error与App180秒等待 | 实物ID、状态、保存与断电载入待确认 |

板载S0/S1/S2/S3与复位控制作用不改，旋钮原有功能不改。完整操作和字段说明见PCB与Flash修复_2026-10-28.md。最终通过项以本轮validation.json为准，历史日志不能替代当前构建。
