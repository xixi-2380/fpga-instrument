> 版本提示：下文保留旧检查点的操作/字段。当前26102902版的松键延音、20Hz颤音和易读PCB默认页，请先看[新版说明](延音与新版PCB界面_2026-10-29.md)；高级详情与旧版的差异也在该文列明。

## 1. 使用哪个工程

打开：`E:\gowin\fpga-instrument-pcb-flash-debug\keyboard_adsr.gprj`。

原测试工程 `E:\gowin\fpga-instrument-integrated\keyboard_adsr.gprj` 保持不变。

**当前源码已将颤音旋钮 SW 改为 W23，但尚未生成包含这次改动的新位流。** 使用新接线前，需要从上述新工程重新编译、生成并烧录位流；旧位流仍可能使用 W25。已按要求停止后续时序优化，诊断页当前保留，计划以后删除。本文描述源码中的操作，不能据此认定开发板已经运行这一版本。

## 2. 接线与开机

三块触摸键盘使用 3.3V 供电，并与开发板共地。三组 I²C 分别连接，不把三板的 SDA/SCL 并在一起。

| 键盘板 | SDA | SCL | INT | 演奏音域 |
|---|---|---|---|---|
| PCB1 | AB25 | AA25 | Y26 | C4～B4 |
| PCB2 | L22 | W26 | U26 | C5～B5 |
| PCB3 | W20 | V19 | U22 | C6～B6 |

| 旋钮 | A | B | SW |
|---|---|---|---|
| 1号：回声（此前称“延音”） | V16 | Y21 | V17 |
| 2号：混响 | U16 | U15 | W21 |
| 3号：颤音 | T23 | R25 | **W23** |

旋钮公共端接 GND。第三块键盘 INT 使用 U22，音频 BCLK 仍为 V22。

开机或重新初始化键盘时，先让手离开触摸电极，等待初始化完成后再演奏。上电默认不自动播放曲谱。退出设置或蓝牙播放结束后，若某键一直按着，应先松开再按。

三板合计提供 36 个琴键。每板另外 4 个 AUX 的菜单、音色、效果和曲库快捷控制已经关闭，仍可在诊断页观察其原始状态。

## 3. 演奏、音色和板载按键

正常演奏时触摸琴键发声；音色可在屏幕设置中选择正弦、长笛、簧管、大提琴、钢琴、木吉他、颤音琴。

板载按键保持原测试工程的作用：

| 按键 | 操作 | 功能 |
|---|---|---|
| S0 | 短按并松开 | 选择正弦音色 |
| S0 | 长按约 0.8 秒 | 进入或退出设置 |
| S1 | 演奏时短按 | 选择长笛 |
| S2 | 演奏时短按 | 选择簧管 |
| S1 / S2 | 设置中短按 | 音量减 / 加 5；超声波接管音量时不执行手动调节 |
| S3 | 短按并松开 | 开关当前选中的效果 |
| S3 | 长按约 0.8 秒 | 按回声→混响→颤音顺序切到下一效果，并开启该效果 |
| 复位按钮 | 按原板卡方式操作 | 执行原有复位；运行期间的 PCB 灵敏度设置恢复默认 |

S0、S3 的长按松开后不会再额外执行一次短按。PCB 页面通过触摸屏操作，不把这些板载按键改成翻页或调参键。

## 4. 三个旋钮怎么用

| 旋钮 | 转动 | 单击 | 双击 |
|---|---|---|---|
| 1号：回声 | 调回声间隔，或调回声强度 | 在“间隔 / 强度”之间切换 | 开关回声 |
| 2号：混响 | 调混响强度 | 选择混响为当前效果 | 开关混响 |
| 3号：颤音 | 调颤音深度，或调颤音速度 | 在“深度 / 速度”之间切换 | 开关颤音 |

回声间隔范围为 20～500ms，每步 10ms；回声强度、混响强度和颤音深度为 0～100%，每步 1%；颤音速度为 1～10Hz，每步 1Hz。

转动或单击会选中相应效果，但不会自动把关闭的效果打开。想听到变化，先双击开启该效果；三种效果可以同时开启。

单击需要等待约 250ms 的双击判定，显示变化会略有延迟。旋钮长按或按住转动不另行触发单击功能。这里“回声间隔”不是 ADSR 包络的松键延音时间。

## 5. 进入 PCB 专项页面

逐行字段、位定义和事件解码见[PCB DEBUG 界面详细说明](PCBDEBUG界面详细说明.md)。

1. 长按 S0 进入设置。
2. 触摸屏上的 `PCB` 入口。
3. 等音量平滑降至静音后，页面显示 `PCB DEBUG / MUTED`。

**PCB 专项页内始终静音。** 观察琴键、转动旋钮和调整参数时听不到声音属于正常行为。按 `BACK` 返回，页面退出后音量平滑恢复；若仍处于设置菜单，长按 S0 回到演奏页。

蓝牙曲谱可能在后台继续推进。校准前可先在 App 中停止播放，避免退出页面后从曲谱中途继续发声。

| 屏幕控件 | 作用 |
|---|---|
| `OVERVIEW` | 看初始化、通信、数据有效、故障和统计 |
| `SENSE` | 编辑并应用灵敏度参数 |
| `BUS` | 看 I²C 现场、NACK、超时及总线事件 |
| `KEYS` | 看两遍原始读值、候选/稳定键值、路由和音符状态 |
| `EC11` | 看旋钮原始/滤波状态、步数、点击、目标参数和效果握手 |
| `PCB - / PCB +` | 选择 PCB1～PCB3；EC11 页同时对应旋钮1～3 |
| `CH - / CH +` | 选择通道 00～0F；00～0B 为琴键，0C～0F 为 AUX |
| `VIEW` | 循环详情页 0～3，具体内容随子页变化 |
| `FREEZE / LIVE` | 冻结 / 恢复显示，采集和故障处理继续运行 |
| `CLEAR` | 清选中板/旋钮的统计和事件；不改参数、不擦 Flash，不清仍存在的故障 |

页面约每 100ms 刷新一次。数字主要使用十六进制：`0A=10`、`0F=15`、`10=16`、`FF=255`。

## 6. 调整三块键盘的灵敏度

### 两个参数的方向

| 参数 | 作用范围 | 默认值 | 增大后的效果 |
|---|---|---|---|
| GSR | 选中板的整体灵敏度 | 02 | **更敏感**；范围 00～0F |
| KOR | 选中板的单个通道 | 04 | **更不敏感**；范围 01～FF |

三板的 02 / 04 是共同起点，不表示已经完成实物校准。

### 调参步骤

1. 在 `SENSE` 中用 `PCB -/+` 选择要调的板。
2. 用 `CH -/+` 选择要调的琴键通道，先从 `00` 开始。
3. 点击 `GSR/KOR` 切换编辑项，再用右下角 `- / +` 修改。
4. 观察 `DRAFT`，确认是想要的编辑值。此时尚未写入键盘。
5. 点击 `APPLY`，让手离开电极，等待 `PENDING / RESULT` 回到 `00000000`，并核对 `APPLIED` 与 `READBACK`。
6. 按 `BACK` 返回，再退出设置，试听该键的按下、松开和误触情况。

例如 PCB2 过于敏感，可以先保持 GSR=02，把某个通道的 KOR 从 04 调到 08，再应用、退出页面测试。此时该通道的 `DRAFT / APPLIED / READBACK` 应显示 `00000208`。每次小幅修改并记录，避免一次改动过大。

若整板都需要相同 KOR，可先编辑当前通道，再点 `ALL KOR` 将该值复制到本板 16 个通道，最后点 `APPLY`。它不会改另外两块板。

| 按钮 / 显示 | 含义 |
|---|---|
| `DRAFT` | 编辑值；未应用前不影响硬件 |
| `APPLIED` | 最后一次整板全部成功应用的配置 |
| `READBACK` | 已验证的实际寄存器回读值 |
| `DEFAULT` | 只将本板编辑值恢复 GSR=02、KOR=04；仍需 `APPLY` |
| `REINIT` | 用最后成功配置重新初始化；从未成功初始化时使用默认备用配置 |
| `NO APPLIED CFG : FFFFFFFF` | 尚无一次完整成功的配置，不能把默认值当成成功结果 |
| `UNVERIFIED READ : FFFFFFFF` | 回读尚未验证；不是电容值，也不是实际灵敏度为全 FF |

**参数只在本次运行期间保存。** 键盘断线后重连会恢复最后成功配置；系统复位或断电后恢复默认，不写入 Flash。校准后请自己记下每板的 GSR 与各通道 KOR。

对于“按不响”，先确认在线、配置回读和数据有效，再尝试减小 KOR 或适当增大 GSR。对于“轻托背面就响”，先适当增大 KOR；若仍异常，再结合供电、共地、接线及安装环境排查。

## 7. 看诊断信息排查问题

### 某一块板没有声音

先进入 `OVERVIEW`，再看 `SENSE` 是否有成功配置和有效回读。如果没有，先处理通信或初始化问题。

在 `KEYS` 中按下、松开琴键，观察原始两遍读值、候选值和稳定值是否变化。专项页本身静音，菜单也会屏蔽手动音符；退出页面、退出菜单，并松开重按后再试听。

### 误触、漏键或反复止音

在 `OVERVIEW / BUS` 观察以下计数是否持续增加：

| 字段 | 如何读 |
|---|---|
| `GOOD CHANGED` | 右四位为一致快照次数，左四位为两遍读值变化次数 |
| `NACK TIMEOUT` | 右四位为 NACK，左四位为总线/时钟超时 |
| `REINIT STALE` | 右四位为重新初始化，左四位为数据过期 |
| `LAST GOOD MS` | 最近一次一致快照的毫秒时间 |
| `AGE MS` | 距最近一致快照已过多少毫秒 |

按下、松开都需要连续两次一致快照确认；极短触摸可能不被接受。两遍读值变化不等于通信掉线。连续 50ms 没有一致快照时，该板停止发音资格，恢复后需松开再按。

`LAST ERROR BYTES` 的八位数字按每两位一组读取：**原因 / 寄存器 / 期望值 / 实际值**。例如 `23072829` 表示寄存器 07 期望为 28、回读为 29，原因 23 是回读不符。

| 原因（十六进制） | 含义 |
|---|---|
| 11 | I²C NACK |
| 12 | 总线或时钟超时 |
| 14 | 按键数据过期 |
| 21 / 22 | 配置写入失败 / 回读失败 |
| 23 | 配置回读与期望不一致 |
| 2F | 非法状态恢复 |
| 31 | 页面配置请求等待就绪或完成超时，显示在配置结果中 |

恢复成功后，最后故障字仍会保留；判断当前是否正常应结合在线、数据有效和当前故障状态。健康时 `CLEAR` 可清掉历史故障字。详细位定义见[专项技术说明](PCB与Flash修复_2026-10-28.md)。

### 旋钮1每格导致 PCB1 状态切换

进入 `EC11`，选择1号，先记录转动、单击、双击和非法跳变计数；再到 PCB1 的 `BUS / OVERVIEW`，比较 NACK、超时、重新初始化和在线状态是否同时变化。`VIEW` 可看旋钮/在线关联事件。

若只有旋钮计数增加，不能据此认定键盘通信掉线；若通信错误同时增加，记录最后故障字和事件。该联动的物理原因尚未通过实板验证。

## 8. 手机 App 下载与 Flash 保存

本工程的诊断 App 为 `0.3.3-pcb-flash-debug`。本地已生成的安装包位于：

`android\build-local\pcb-flash-debug\GaoshanScore-0.3.3-pcb-flash-debug.apk`

### 首次连接和下载

1. 在 Android 系统蓝牙设置中配对琴端蓝牙模块。
2. 打开 App，点 `连接蓝牙模块`，选择已配对设备。
3. 连接后另点 `验证 FPGA 通信（HELLO）`，确认设备能力和状态已返回。
4. 先用 `三音符示例` 测试；正常后再 `导入 MIDI`，选择轨道、通道和移调，点 `应用筛选与移调` 检查预览。
5. 在“琴端曲库”选择目标编号 S001～S032，确认是否会替换已有曲目。
6. 点 `下载到琴` 并确认。先完成 RAM 上传与校验；设备支持可写曲库时，随后自动保存到选定 Flash 编号。
7. 等到明确显示 `已持久保存 Sxxx`，再做断电重启验证。

`RAM已校验` 或 `RAM下载完成` 只说明曲谱已进入内存。若显示“Flash尚不可写”“Flash保存未确认”或“结果未知”，不能据此认为断电后仍会保留。

### 曲库和播放

| App 按钮 | 作用 |
|---|---|
| `播放 / 暂停 / 继续 / 停止` | 控制琴端播放 |
| `保存当前RAM` | 将内存中的曲谱保存到选中编号；确认后替换该编号已有曲目 |
| `刷新曲库目录` | 读取 S001～S032 的实际目录 |
| `加载选中曲谱` | 从 Flash 载入 RAM，完成后不会自动播放；再点 `播放` |
| `删除选中曲谱` | 确认后删除选中编号 |
| `读取Flash诊断` | 读取 ID、状态及写入能力等诊断 |
| `查询未完成任务` | 查询此前保留的任务结果 |
| `复制诊断记录` | 复制连接、错误和任务信息，便于排查 |

等待 Flash 任务的总预算为 180 秒。等待超时、取消等待或断开蓝牙后，琴端已开始的任务可能继续运行。保留任务编号，重连原模块后点 `查询未完成任务`，先确认结果再决定下一步，避免重复发起保存。

断电验证：先确认持久保存成功，再关闭电源；重启并连接后刷新目录，选中原编号，加载到 RAM，再播放。App 的 `离线演示` 使用手机模拟设备，不会让开发板发声，也不能验证实物 Flash。

## 9. 屏幕上的其他入口

设置页保留音量、音色、效果、恢复默认、`ULTRA` 超声波和 `more` 曲库入口。

`ULTRA` 页面可开关超声波音量控制、调整灵敏度和音量上下限。开启后由超声波控制音量；需要用 S1/S2 或屏幕手动调音量时，先关闭超声波接管。

`more` 页面可选曲目编号、加载、播放、暂停、继续、停止、保存当前 RAM、删除及查看 Flash 信息。加载和播放是两个操作。AUX 快捷控制已经关闭，使用触摸屏上的对应按钮。

## 10. 建议的首次测试顺序

1. 核对实际位流来自当前新工程，颤音 SW 已接 W23。
2. 先不接触电极开机，退出设置，逐板测试单键和松键。
3. 进入 PCB 页，检查三板配置、回读、通信和数据有效情况。
4. 分别调三板灵敏度，每次应用后退出页面试听，并记录参数。
5. 测三个旋钮的转动、单击、双击；观察旋钮1是否仍与 PCB1 状态联动。
6. 用 App 三音符示例测试 RAM 下载，再确认 Flash 持久保存及断电载入。
7. 最后测试多声部曲谱与多效果叠加。记录实际噪声、供电和音量条件；仿真通过不代表这些实板现象已经消失。
