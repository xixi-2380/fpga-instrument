## 下载前

先核对实板版本及完整器件，生成正式 CST、源同步音频输出约束并完成 P&R/STA。
此时才能填入 hardware_status.json 的签核项。program_sram.py 在缺失时拒绝调用下载器。
只使用 SRAM Program and Verify，不写 Flash，不改板载调试器固件。
离线可行性构建没有已签核 CST，自动分配引脚的 bitstream 绝不能下载。

## 测量顺序

1. 从匹配原理图识别 GND 和可达探测位置；不假定测试点编号。
2. 功放关闭时检查 DAC 引脚处 BCK/WS/DIN，核对电平、边沿和 16 次采样/通道。
3. 连续零码后使能功放，确认模拟输出无异常，再播放低幅正弦。
4. 先双声道同音，再左独响和右独响，核对最终插座通道。
5. 在播放期间复位，观察静音、重锁和帧边界恢复。
6. 连续播放至少 30 分钟，保存时间、仪器精度、测量结果和 bitstream SHA-256。

PT8211 是 Japanese/LSBJ：WS=0 右、WS=1 左，MSB 先行，BCK 上升沿采样。
官方例程的通道注释与芯片手册不一致，本工程依手册实现，仍需左右实测。
没有 Note 输入，本轮不能证明 <5 ms 演奏响应。
