## 2. 当前证据与优先级

### 2.1 现有实现报告仍有时序违例：P0

读取已有 `impl/pnr/D2_keyboard_leds.tr`，生成时间 2026-10-24 17:50:08，设计文件指向本工作树。总 Setup 违例端点1276，Hold违例端点0。分类如下：

| 时钟 | 要求 | 报告 Fmax | 内部 setup 负裕量端点 |
|---|---:|---:|---:|
| ref_clk | 50MHz | 58.678MHz | 0 |
| audio_clk | 61.44MHz | 55.847MHz | 257 |
| pixel_clk | 35MHz | 33.134MHz | 18 |

总1276还涉及报告中的其他路径/输出预算，不能全部称为音频内部违例。音频已列出的负裕量路径包括 timing/count 至包络 remainder、render_cycle 至 visual_notes；显示输出存在6ns路线预算违例，日志也出现转发时钟 clk_d 使用普通布线的 PR1014。此证据改变处理顺序：先排除时序不满足，再判断算法音质。报告不能证明这些路径就是主观听感的实际成因，也不能证明板内固件与报告完全相同。

### 2.2 蓝牙每次起音会硬清音源与效果器：P1

`src/bluetooth_audio_bridge.sv` 中 On 事件先进入 CLEAR；`flush` 会复位合成声部、效果器状态和音频缓冲。旧声音处于非零幅度时，硬清除可能产生样本突变，效果尾音也被截断。这是明确需要检验的机制，不是已经用录音证实的根因。当前策略是为保持单自动调度声部与可靠静音而实现的。

### 2.3 波表与音色因素：P2

当前4096点波表由32位相位直接取高12位寻址，没有相邻点插值。七音色采用有限谐波近似，音色本身不等同于录制乐器。应比较原始波形、包络和最终PCM，确认不平滑来自寻址误差、过渡还是谐波分布。

现有生成脚本最高采用第10次谐波；蓝牙音域MIDI48～83，最高基频约987.77Hz，第10次约9.88kHz，低于48kHz采样的24kHz奈奎斯特频率。因而不能仅凭音色较亮就判定主要谐波越界混叠；仍需实测离散寻址误差和调制产生的杂散。扩展音域或波形之后再评估分段带限波表。

### 2.4 量化与响度因素：P2/P3

目前每声部保留1/32增益，混音和效果器主接口为16位。单音数字电平较低，包络尾端与反复舍入可能值得比较；不能把后级提高音量等同于恢复已经丢失的精度。现有移位取整方式、负数偏差、效果器残留需要数学参考检验。提升总增益会同时放大原有误差，应放在定位之后。

## 3. 实施顺序与交付

### 阶段A：冻结对照与定位，不改变听感

1. 固定工程路径、源码 SHA256、综合/实现报告与下载文件 SHA256，记录用户实际下载的是哪个文件。保留既有失败报告。
2. 建立对照矩阵：正弦与其余六音色；效果关闭/回声/房间/颤音；手动与蓝牙；低中高音；持续音、重复音、相邻换音、普通和弦、松键与暂停/停止。先跑短代表用例，发现差异再扩展。
3. 从实际 RTL 导出波表/包络后、混音后、效果器后、最终PCM与外部I²S解码数据，生成48kHz WAV和频谱。对照试听同时保留原始幅度版本与等响度版本，避免把“更响”误判成“更平滑”。
4. 软件参考按同一相位、力度、音色和节奏生成理想波形；频谱分析采用一致窗函数或相干采样，区分预期谐波、量化杂散与频谱泄漏。检查平均值、峰值、饱和计数、欠载、交接附近的额外误差。相邻采样差不能单独作为噪声判据，高频正常音也可能有较大的差值。
5. 先分析最新 STA 的实际关键路径、时钟/输出约束与源代码对应关系，形成时序修复清单。

交付：可复现用例、源码/实现身份记录、PCM/WAV、频谱与误差对照、STA问题列表。若数字PCM正常而模拟端仍有杂声，再用用户实测的差分音频、供电和波形区分模拟问题，不通过滤波掩盖。

### 阶段B：先修时序与声音交接

时序方面：优先拆分关键组合路径、寄存显示音符解码/包络控制中间结果、控制帧使能扇出，并检查LCD输出与转发时钟的实现方式。保持采样率和既有PLL功能，不以统一降频、宽泛false path或未经证明的multicycle掩盖问题。输出路线预算要与真实接口需求分别核对，不为了消除红字直接放宽。每项修改后运行HDL对照；用户重新实现检查全部时钟、setup/hold及I/O要求。

交接方面：对蓝牙换音、手动抢占、同编号跨音色重触发、暂停/停止分别设计连续过渡。评估短淡出后切换再淡入，或内部有限交叉渐变；保留同音重触发原本的相位/包络连续性。自动调度仍声明1声部，不扩大协议能力。内部过渡是否允许短交叠，须连同单声部语义与测量结果确定。

不能直接给每个蓝牙 On 增加数毫秒等待：播放器以1ms推进且带deadline检测。先以16/32采样的短过渡作为模型候选，核算CDC、音源握手、帧边界及命令完成时间；若超出预算，调整交接架构而不是吞掉事件或冻结音乐时间。最终参数通过听感和误差测试选定，不承诺这些短过渡必然充分。

暂停、STOP、上传接管和复位必须排空/取消过渡缓存，并在实际左右I²S静音后确认；不通过反复重启BCLK/LRCLK或功放实现平滑。

### 阶段C：按证据改善波表与数值精度

- 若模型显示寻址量化杂散明显，优先评估线性插值：同一音色读取相邻两点，使用相位低位的部分位作为插值权重，末地址回绕。复用每声部现有16周期时间槽，采用同步ROM逐拍读取，保持音色/相位/首尾标志对齐；避免复制所有七套ROM或长组合乘加。实际ROM/DSP代价由综合确认。
- 检查起音/衰减曲线的接缝与音色切换，修复额外不连续，不以延长全部Attack抹掉钢琴/吉他的正常瞬态。
- 若低电平尾音误差明显，比较内部增加小数位、对称舍入与现有取整；优先保留内部精度，最后一次量化。效果器RAM位宽扩展会影响BRAM和路由，须独立评估，避免一次性扩大所有存储。零输入必须稳定回到精确零。
- 每一项只与前一项通过的版本比较，不能同时改谐波、包络、插值和增益后再凭听感猜原因。

交付：带相同响度的A/B音频、误差/杂散对比、延迟和资源估算；只保留有实际收益的修改。

### 阶段D：条件性评估FIR音色修整与输出响度

FIR不是默认修复。若阶段A～C证据显示需要高频修整，再离线设计31/63抽头对称FIR候选，给出通带、阻带、纹波、衰减和量化系数。截止频率依据七音色频谱选择，不能预先固定为很低的数值。31/63抽头线性相位FIR在48kHz下群延迟约0.3125/0.6458ms。

采用同一音频时钟加采样CE、同步样本缓存和复用MAC，禁止把全部抽头组合展开。验证全链路的1280周期采样预算和上下游握手，旁路与滤波路径需延迟对齐。FIR可以改变高频质感，但不能恢复掉样、修复时序、恢复已削波波形或撤销已经折叠到低频的混叠。

响度改进沿用此前研究的“固定增益校准＋峰值限幅＋用户音量”方向。16/24倍补偿与短前瞻仅为候选，需比较和弦、七音色瞬态及尾音，不让限幅器长期深度压缩正常演奏。新增前瞻缓冲必须纳入暂停/停止清零和播放延迟预算。将这一步与平滑度修复分开验收，避免增益变化掩盖原因。

## 4. 验收标准

| 项目 | 判定依据 |
|---|---|
| 时序正确性 | 用户提供与源码/下载文件匹配的新报告；全部工作时钟及真实I/O要求满足，所有违例已解决或有可验证的约束依据 |
| PCM与串行连续性 | 每帧恰好一对样本；外部边沿解码与参考位精确一致，无欠载、丢帧、丢事件或意外符号翻转 |
| 过渡 | 交接符合所选淡入/淡出模型；同相位/同节奏参考比较无额外硬截断；实际试听覆盖连续换音、同音重触发、停止与返回手动 |
| 数值与频谱 | 未限幅区域符合定点数学参考；无溢出回绕、意外DC或持续量化残留；杂散改善不以错误删去正常音色谐波换取 |
| 静音与尾音 | 无声部且效果尾音结束后归零；音量0精确静音；STOP/暂停与复位不会回放旧缓存 |
| 性能与接口 | 新增计算满足音频帧与1ms调度预算；协议能力、键位、UI、触摸、MAX引脚及原音色选择保留 |
| 听感 | 用户在相同音色、音高、效果设置和匹配响度下A/B确认改善，同时保留原始电平记录 |

不预先填写无法由当前硬件证据支持的SNR、THD或模拟输出功率指标。仿真结果不替代实板试听与测量。
