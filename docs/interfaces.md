# 模块接口和固定周期约定

## 时钟与复位

参考 50 MHz；PLL 1：IDIV=1/FBDIV=1/MDIV=16/ODIV0=25，输出 32 MHz、VCO 800 MHz。
PLL 2：IDIV=1/FBDIV=1/MDIV=24/ODIV0=12.5（整数 12、1/8 分数值 4），输出 61.44 MHz、VCO 768 MHz。
PFD 分别为 50/32 MHz，满足工具要求的 19..81.25 MHz。原 50→96→61.44 MHz 候选因 PFD 不合法已废弃，错误报告保留。
使用 GW5AST-138 的 PLL 原语，内部反馈、静态配置；没有组合逻辑派生时钟。
PLL 2 在 PLL 1 连续稳定 100000 个 50 MHz 周期后解除复位；第二级再资格判断 2 ms。
LOCK 低会异步断言安全复位，释放经过本域两级同步。上电 POR 计数器使用 Gowin 可综合寄存器初始化。
失锁时直接静音；恢复必须重新锁定并走完整启动流程。

## 音频周期

所有音频 RTL 在 audio_clk 上升沿运行。BCK 是寄存器输出，正常高低各 20 个周期。
每 1280 周期一立体声帧。bit_index 0..15 为右、16..31 为左。
frame_ce 与右声道 MSB 的第一个下降沿同拍；DIN/WS 此时更新，上升沿采样。
复位将 BCK 置高、WS/DIN 置零；首次下降沿建立右 MSB，随后第一上升沿采样。
复位可打断当前帧，下一次运行从完整右/左帧开始。

## 数据与握手

phase 为无符号 U0.32 周相位；FCW 为每样本周期相位增量。sample_ce 每帧推进一次。
ROM 地址 phase[31:20]，4096x16 有符号 Q1.15，同步读，valid 与 ROM 输出同拍有效。
tone_gain 将输入拼接 8 个零扩展为 Q1.23；level 为无符号 Q1.16（0..65536）。
先以 42 位有符号乘积保存，再算术右移 29 位，实现 level/65536、1/32 增益及 24→16 位转换。
舍入规则为算术截断（向负无穷）；最终饱和到 [-32768,32767]。初始峰值约 [-1024,1023]。

frame_buffer 使用 sample_valid/sample_ready、sample_l/sample_r 成对接收。
valid && !ready 时生产者必须保持 valid 和左右数据；本实验闭合流水线在帧后两周期提交，永远有空闲缓冲，TB 检查此假设。
每帧先消耗旧 pending 对，再接收本拍新样本；边界同拍交付的样本属于下一帧，无直通旁路。
缺样本发零，除预期初帧外置位 sticky underrun；复位清除标志。

启动先完整发送 480 帧零码，在索引 480 的帧边界开启 PA，后续 240 帧令 level 从 0 线性增加至 65536。
一帧缓冲使数字淡入样本晚一帧到串行输出。channel_mode=0 双声道、1 左独响、2 右独响。
FCW/channel_mode 在本阶段为顶层静态参数；后续动态控制必须通过原子帧边界快照，不允许直接异步改动。

## 下一阶段

保留 32 位相位、12 位波表地址、24 位声部、40 位混音、16 位 DAC。
调度约束 32*slot_cycles+overhead<=1280。控制事件跨域用握手快照或异步 FIFO。
音频发送不等待事件队列，也不因控制突发而停钟。

## D0 GPIO 镜像诊断接口

bringup_digital 新增四个单向输出：DBG_BCK=HP_BCK（C24）、DBG_WS=HP_WS（B24）、DBG_DIN=HP_DIN（E25）、DBG_PA_EN=PA_EN（D25）。仅内部信号扇出，原串行时序不变；无新增 CDC 或内部时钟。诊断版数据与功放使能固定零。物理输出存在各自路径延迟，不视为 DAC 引脚电气测量。

## D1 单音板级接口

tone_play_board 及其 stereo/left/right 入口保留 10 个板级端口：clk/rst、HP_BCK/HP_WS/HP_DIN/PA_EN、DBG_BCK/DBG_WS/DBG_DIN/DBG_PA_EN。区别是 DIN 和 PA_EN 由真实单音核心驱动，不再固定零。DBG 端口仅扇出；外部输入仍只有复位，本阶段没有控制输入。默认配置在 synth_config.svh；仅声道模式为三个顶层常量。

## 启动状态灯只读诊断

run_leds仅在ref_clk域运行，新增PLL1/PLL2 LOCK和外部复位的两级同步观察。未就绪持续RUN_LED_DIAG_STEPS个流水步进后，低四位改为心跳/LOCK1/LOCK2/复位显示；就绪时恢复四灯流水。LED4/5仍为同步后的音频复位解除/音符门控。该显示没有反向控制路径，原时钟、复位、锁定2ms资格和音频帧握手不变。原始LOCK显示不能代表连续稳定资格已满足。
