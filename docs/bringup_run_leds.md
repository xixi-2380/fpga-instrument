## 六颗橙色用户灯的含义

| 逻辑灯号 | 球位 | 4071f3图纸灯号 | 正常就绪时 | 持续未就绪约1秒后的诊断模式 |
|---|---|---|---|---|
| LED0 | R26 | LED1 | 四灯流水第1颗 | 参考时钟心跳，约250ms亮/250ms灭 |
| LED1 | J14 | LED0 | 四灯流水第2颗 | PLL1原始锁定指示经同步后为高时亮 |
| LED2 | L20 | LED2 | 四灯流水第3颗 | PLL2原始锁定指示经同步后为高时亮 |
| LED3 | M25 | LED3 | 四灯流水第4颗 | U4复位输入为高时亮 |
| LED4 | N21 | LED4 | 音频域复位解除后亮 | 保持原含义，未解除复位时灭 |
| LED5 | N23 | LED5 | 音符门控有效时亮 | 保持原含义，未就绪时通常灭 |

按逻辑灯号 LED0→LED1→LED2→LED3→LED0，即球位 R26→J14→L20→M25→R26，每颗停留 250 ms，一圈约 1 秒。
若按 4071f3 原理图灯号观察，顺序为 LED1→LED0→LED2→LED3；重新配置从 R26 对应的灯开始。
运行灯和诊断显示均直接使用板载50MHz参考时钟。上电先流水；持续未就绪达到4个250ms步进后转为诊断显示，不再要求四灯轮流亮。再次失去就绪时约0.75～1秒后也会切换；就绪恢复即自动恢复四灯流水。
短按USR仍有运行指示，长按超过约1秒后LED3应表示复位为高，LED0心跳继续。
PLL1/2 LOCK、U4复位、音频就绪和门控各经两级同步，只观察、不反馈控制，不改变PLL频率、锁定资格判断、复位、扫描或功放启动。
LED5 表示 Note 门控而非波形幅度：松开后它可以立即灭，而 200 ms Release 尾音仍继续。
这里指六颗普通用户灯，不是 POWER/DONE/READY 灯或 WS2812 彩灯。

## 依据和约束

六路 LED 引脚设为 LVCMOS33、无上拉、DRIVE=8，未占用键盘及音频测量球位。24 个板级端口球位唯一性检查通过。

## 如何判断

- 上电约1秒后LED4仍灭，应读取诊断模式；LED0心跳表示参考时钟域仍在运行。
- LED3亮：优先检查U4复位输入是否一直为高；USR是核心板上、散热片右侧靠上的按钮，下方RECFG是重新配置。
- LED3灭、LED1灭：优先查PLL1与50MHz参考路径。
- LED3灭、LED1亮、LED2灭：优先查PLL2或PLL1未能连续稳定锁定。
- LED1/2均亮但LED4灭：不能仅凭肉眼判断LOCK已连续稳定2ms，需考虑短暂失锁、资格判断或音频时钟未运行。
- LED4亮后自动恢复四灯流水；此时LED1/2/3又是流水灯，不再表示上述诊断状态。
- LED4亮但按单键LED5不亮，继续查键盘扫描；用户当前已反馈温机后可识别并发声。
- 恢复后松键LED5灭但仍有持续底噪：数字空闲零码已有仿真检查，实板DIN未知，仍需区分数字接口与DAC/功放/供电噪声。

灯光只帮助定位，不能证明音频时序或电气验收。最新用户反馈为“冷启动数分钟后能发声，持续空闲低频嘶声”，短按USR无效；这两项原因仍未确定。

## 仿真和参数

src/config/run_leds_config.svh 定义运行灯周期，默认 REF_HZ/4=12500000 个参考周期。
run_leds 用配置初始化的计数器循环，不用用户复位或 PLL 作时钟。
独立 tb_run_leds 检查上电状态、完整循环、精确间隔、STEP_CYCLES=1 边界、状态同步与 PLL 就绪撤销。
板级 tb_keyboard_top 检查音频和键盘保持正常、音频/按键状态灯点亮及用户复位期间流水继续。
