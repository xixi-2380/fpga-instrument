# main功能整合与验收

本次以最佳实测DDS版为音频/键盘基础，整合main的主题与分析显示，以及integrated-instrument的触屏箜篌、滑音和Chorus。录制、自定义键位、旧矩阵/DBG、PCB诊断、S0～S3和上电自动播放按用户决定退出生产功能。

当前状态：功能整合完成、行为回归进行最终核验，完整综合/布局布线正在进行。尚无与本次源码匹配并通过完整STA的位流。旧DDS位流的128个setup违例不属于本次验收结果。

## 保留的功能

- 48kHz、32声部、36个实体琴键、16种旋律音色与10种鼓音、左右声道独立效果/限幅。
- 逐声部20～2000ms松键延音、混响、Tremolo和立体声Chorus。旧PCM回声关闭。
- 十二弦触屏箜篌、扫弦、重拨，实体琴键和触屏事件仲裁。
- 手机蓝牙MIDI上传/播放/暂停/继续/停止与32首Flash歌曲曲库；App采用0.4功能范围，舍去录制/自定义键位扩展。
- 四种主题（含小猫、卡皮巴拉动画与隐藏人物彩蛋）、中英文、波形、电平、琴键高亮、2048点/64频带FFT、现有16采样延迟XY。
- 三块AiP5916键盘正常扫描、断线松键与重新接入、统一GSR/KOR设置和读回校验。

## 本次操作变更

| 操作 | 当前功能 |
| --- | --- |
| 第一旋钮 | 调松键延音时间/强度；单击切换调节项，双击开关延音 |
| 第二旋钮 | 主音量0～100，每格1；按下不分配其他功能 |
| 第三旋钮 | 调Tremolo深度/速率；单击切换调节项，双击开关 |
| 屏幕音量按钮 | 仍调主音量，每次5 |
| 超声波 | 默认关闭，启用后控制约±2半音连续滑音；无有效距离时平滑回中，不调音量 |
| 屏幕滑音条 | 删除；传感器是滑音输入来源 |
| 混响、Chorus | 在屏幕中开关和调节参数 |
| 主题、语言、视图、彩蛋 | 主屏幕底部按钮 |
| 整体灵敏度 | 设置中的GSR/KOR，统一应用到三块板各通道，默认2/4；不存Flash |
| USR | 系统复位，回到无自动演奏的待机状态 |

## 修复与滤波

`key_note_events.sv`在输入被禁用后仍排空已接受按键的NoteOff，顶层不再因为进入菜单/临时来源切换而抹掉手动事件的记账。只有音频引擎清空时同步清空记账，避免已发NoteOn失去对应的NoteOff。独立复现和生产链路测试已覆盖相关场景；最终实板是否还有其他原因，需要结合合格时序版本验证。

主音量之后、最终PCM输出之前加入左右声道各自的DC去除与低通：DC拐点约1.87Hz、低通约15.74kHz，移位/加法实现。滤波输出用于音频和分析显示。流水线保留valid和事件标签；音量零的平滑斜坡结束后清除滤波历史，保持严格数字静音。详细公式和数值证据见output_filter_20261101.md。

## 验证入口

在项目根目录运行Python脚本。测试默认使用本机已安装的Icarus工具路径；其他机器可按各脚本参数指定或调整工具位置。

- `scripts/run_main_top_test.py`：真实三板I²C、实体键、菜单、传感器/音量独立、箜篌、来源切换和清音。
- `scripts/run_control_integration_tests.py`：旋钮/触屏、超声波映射、三板灵敏度CDC与箜篌边界。
- `scripts/run_release_bug_tests.py`：松键持续发声复现与修复、背压和1/4/32声部。
- `scripts/run_merged_display_tests.py`：触屏矩形、像素流水线、中英文/主题/FFT/XY与页面快照。
- `scripts/run_output_filter_tests.py`和`run_filter_core_tests.py`：整数/浮点参考、频率响应、双声道流水线、严格静音和外部I²S。
- `scripts/build_keyboard.py --stage syn --out-dir reports/integration_20261101/synthesis_initial`：高云官方综合。旧脚本的all/package仍是历史回归集合，当前整合请使用本次独立验收报告，不把旧回归的端口期望视为当前规格。

行为仿真采用显式行为PLL，不等同STA或实板验证。最终物理验收必须核对当前源码/约束/网表/位流哈希、69个真实管脚、完整布通、setup/hold、内部裕量和LCD转发时钟SDF；不自动烧录。
