## 独立数学参考

新增 `scripts/check_xy_adjustment.py`，使用精确整数比例生成每条线的参考：沿较长坐标轴逐点推进，另一轴按准确比例四舍五入，半格朝本线起点外侧取整。参考没有复用 RTL 的 Bresenham 误差更新，也没有沿用原先仅三幅波形的 Pillow 检查。

|---|---|---|

**总计 7,467,237 项检查通过。** 原始 signed-byte 坐标到 `[0,63]` 的转换正确，极端线段不会绕边或卡死；实际最大误差寄存器绝对值为 93，原有有符号 8 位足够。每条线最多 64 个绘点。一次完整构图保持原有 4096 点清理及有界连线过程；没有发现需要增加位宽或 RAM 的理由。

输入波形在 start 时锁存，随后改变输入不会污染正在构建的图。旧前台保持可读，完成的后台只在 frame_tick 发布；同拍发布/start 将旧前台作为新后台。任何可见前台都不会被清理/绘制写入。复位使 ready 失效，新图完成前不会泄漏旧 RAM。零信号被下一幅完整静音图替换为 `(32,31)` 中心单点，不保留前一幅曲线。

## 屏幕连接只读检查

主代理负责屏幕/超声波修改，本项没有改 `rgb_ui_renderer.sv` 或 `rgb_display.sv`。只读检查确认：

- `audio_visualizer` 每四个有效 PCM 采样取一个 signed 高字节，完整快照为 128 点。
- `phase_plot` 接原波形状态 `[1111:88]`，Y 轴比 X 轴早四个快照点，仍等于原单声道 **16 个音频采样**延迟。没有改成 L/R 声道图。
- 普通主题将 64×64 位图放大到 x=376～503/y=170～297，隐藏主题保持 x=680～743/y=172～235。原边界门控和坐标缩放一致。
- 位图像素为同步一拍读出；渲染器在下一阶段叠加到同一坐标的前景色，和既有像素管线相位一致。
- frame-locked 状态桥与绘图模块同拍更新时，绘图可能使用上一份完整波形快照，意味着一帧级观察延迟，不是半帧撕裂或错误坐标。没有据此改变原显示行为。

这些连接检查属于源级审阅；新数学/缓冲测试直接执行了实际绘图模块，不等于重跑整套 RGB/LCD 实板验收。若实板异常仍出现，异常图、对应输入音色/频率和触发页面切换步骤可用于继续定位；当前保留用户已实板成功的实现。
