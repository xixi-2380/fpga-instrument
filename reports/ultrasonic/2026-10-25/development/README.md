# 开发问题与修正

1. 最早版本复位后立即触发，测距 TB 检出了复位边界两次触发间隔不足 60 ms。已将复位后的首次触发也延后完整 60 ms；1 MHz / 50 MHz 的相同用例均通过。原失败见 reset_trigger_interval_failure.log。
2. 第一次跨域接线放在外层时钟/复位信号声明之前，Icarus 在 generate 作用域推导出隐式本地网线，导致桥接信号未正确连接。四态串行回归检出错误。已把 generate 接入块移至全部外层信号声明之后；后续编译无隐式网线提示，原曲谱/I²S回归通过。原失败及编译提示见 gain_connection_*。
3. 新集成 TB 在第一个参考时钟到来前将未知 audio_reset 视为已释放，导致过早检查未知输出；已让记分板在复位未明确为 0 时保持初始化。没有修改生产复位算法。原失败见 initial_unknown_state_check_failure.log。
4. 本环境的 Verilator wheel 缺少预编译头包含选项；通过可选 make 参数解决本地 C++ 构建，不改生产 RTL。含高阻矩阵与未知态的集成以 Icarus 四态结果为准。
5. 未压缩的双音源长时间测距集成运行成本过高，不计为通过。本轮将真实传感器计时交给独立 50 MHz 单元测试，跨域/音频集成按 TB 明示的参数压缩测距时间，并单独覆盖默认音频渐变参数。没有把测试覆盖参数写入生产源码。

原始开发目录留在工作区；交付只保存相关文本失败记录，不提交二进制、VVP 或本机编译缓存。
